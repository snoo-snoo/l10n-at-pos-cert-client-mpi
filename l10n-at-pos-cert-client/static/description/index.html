Module Outstanding Feature

RKSV-Compliant POS Invoices

Electronic POS/transaction invoice characters according to RKSV standards.

Legal QR Code & Signature Printing

Print QR codes or signature strings on invoices to meet legal requirements.

Austrian POS Compliance Receipts

Only for companies with POS which are required by Austrian law to have this qr printed on their receipts.

Transaction Log Storage & Export (DEP)

Automated Special Receipts (Start, Null, Cancel)

Cloud Integration

Technical Implementation with Fiskaly API: The Fiskaly Cloud TSS replaces local signature hardware and handles RKSV signing in the cloud.

Sales Process & Electronic Signature

Create an order in POS as usual.

When paying, POS sends transaction data (amount, tax, time, invoice number, revenue counter number…) to RKSV electronic signature service.
Return signature service:
Electronic signature string.
QR code containing transaction information.

POS:
Print invoice with signature/QR code.
Save signature and transaction data to backend for auditing.

Data Export & Storage

By law, Datenerfassungsprotokoll (data log) must be exported and stored at least quarterly.

The module allows exporting this file for each POS for storage or sending to the tax authorities.

Set Up & Activate POS Certification

Access Company Configuration
Go to Settings → Users & Companies → Companies.
Select the company you want to configure (e.g., Clothing Store)
Open the POS Certification Tab>
Inside the company profile, click on the POS Certification tab.

You will see key fields:
Admin Module URL – the endpoint provided by your fiscalization service (e.g., Fiskaly).
API Key – the authentication key from your provider.
Activate POS Certification – button to start the certification process.
Subscription Status – shows whether your subscription is active. 
Organization Status – shows whether your organization is created in the provider’s system.

Activate POS Certification:
Click Activate POS Certification.
The system will:
1. Create your Organization in the provider’s system (if not already created).
2. Link your POS to a TSS (Technical Security System) in the cloud.
3. Update Subscription Status and Organization Status.
Create Organization: Click to create an Organization and begin the RKSV compliance process.
